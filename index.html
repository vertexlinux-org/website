The Project

More than another Linux distribution with different branding.

Vertex Linux is being developed with a simple long-term goal: create a genuinely useful Linux distribution rather than simply repackaging an existing system.

Vertex will initially use Arch Linux as its foundation. This gives the project access to mature packaging infrastructure, a huge software ecosystem and a minimal base while Vertex itself is still young.

That foundation is a starting point, not the final destination. Vertex will gradually introduce its own repositories, packages, installer and system tooling as the project matures.

Design Principles

Keep what works. Build what matters.

01

Usable first

Vertex does not need to become independent overnight. A reliable operating system matters more than replacing software simply for the sake of replacing it.

02

User control

Vertex should remain understandable and configurable. The operating system should work for its user rather than hiding the system from them.

03

Reliability

The project aims to eventually add additional testing, recovery mechanisms and update safeguards around its rolling foundation.

04

Minimal when wanted

A TTY-only installation will remain a valid way to use Vertex. Graphical environments should be choices rather than requirements.

05

Incremental development

Vertex will be built one working layer at a time, with development tracked in Git and known-good milestones preserved.

06

Purposeful independence

Vertex-specific replacements should exist because they improve the system, not because independence makes for a better marketing claim.

Roadmap

Start with a terminal. Build from there.

Vertex has ambitious long-term ideas, but none of them matter without a dependable base system. Development therefore begins with the smallest genuinely useful milestone.

0.0.1 - Bootable Foundation

Build a Vertex installation ISO capable of installing onto a blank machine and booting independently into a working TTY with networking and package management.

Vertex Installer

Develop a dedicated terminal-based installer capable of performing a normal installation while always providing access to an emergency shell.

Vertex Repositories

Introduce repositories containing Vertex packages, configuration, system tooling and other project-maintained components.

Desktop

Add optional lightweight graphical environments, with XFCE and Sway among the environments currently being considered.

System Tooling

Develop Vertex-native tools where they can make installation, configuration, updates and system management simpler or safer.

Greater Independence

Gradually replace selected upstream components when Vertex can provide an implementation with a genuine technical benefit.

Current Milestone

Vertex Linux 0.0.1

Vertex Linux is currently in very early development and is not yet available as a stable operating system for general use.

Right now, the objective is intentionally simple: install Vertex onto a blank virtual machine, remove the installation media and boot the installed system successfully.

Definition of done for 0.0.1

Vertex installs onto a blank VM, boots from its installed disk without the ISO attached, provides a working TTY login, connects to the network and can install and update packages.

Looking Ahead

A distro that earns its own identity.

Future ideas include curated Vertex repositories, safer updates and snapshots, lightweight desktop options and potentially a simple declarative configuration system for packages, services and other system settings.

These are long-term directions rather than promises for the first release. Vertex will grow incrementally, keeping a working system at the centre of development.
